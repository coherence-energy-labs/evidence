# Public review visibility and intellectual property

The material is visible for independent scientific scrutiny. No general open-source license is granted by this draft alone; Coherence Energy Labs should select one before any release intended for redistribution. Public release of source experimental counts is deliberate; names of users, account credentials, tokens, local filesystem paths, private source modules, and unrelated research artifacts are excluded.

Data headers and raw-record source Git blob IDs are **provenance references supplied by the author**, not independently authenticated IBM job signatures. Original hardware QPY, calibration records and full pre-submission witness package have not been published, and the reader must not be led to believe otherwise.
